# UkoreHub (dev repo)

This is the dev repo for UkoreHub — a Git repo launcher/pipeline tool for
Ukore Studio, built on PySide6.

- **[`app/`](app/README.md)** — the actual application. Start here for
  what UkoreHub does, prerequisites, and how to run it.
- **[`developer/launcher/`](developer/launcher/README.md)** — the
  `UkoreHubLauncher.exe` at this repo's root (double-click it to launch
  `app/` for testing, without it auto-updating over your local work — see
  that README's "Dev mode" section).
- **[`developer/`](developer/README.md)** — everything else dev-only: the
  two release commands (`git release-app`, `git release-launcher`), bug
  history, and the app's test suite.
- **[`CLAUDE.md`](CLAUDE.md)** — instructions for working in this repo
  with Claude Code.
